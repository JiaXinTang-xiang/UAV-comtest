# 仓库与依赖管理

统一提交地址：https://github.com/JiaXinTang-xiang/UAV-comtest.git

## 提交范围

- 比赛工程、启动脚本、场景、文档、试题材料。
- PX4、Gazebo 插件、OpticalFlow、Micro-CDR 等本地依赖源码快照，包括本地修改和许可证。
- 本次左路线完整成功的任务 JSON、飞控 JSON 和 CSV。
- 依赖的原始仓库地址及提交号记录在 `dependency-sources.json`。
- 本次排障图片、终端附件与成功控制台输出保存在 `现场记录/2026-10-22/`。

PX4 和 Micro-CDR 在主仓库中作为普通源码文件保存，不再使用没有 `.gitmodules` 映射的仓库指针。克隆主仓库可得到这些源码。

## 本机目录处理

编译产物（build/install/log）、Python 缓存、实时仿真日志、旧训练日志和下载包不再纳入新提交，但本机文件保留。该操作不会清理运行中的仿真，也不重写主仓库旧历史。

依赖目录中的 `.git` 不上传。当前 PX4 Makefile、版本生成脚本及子模块构建规则依赖这些元数据，本机保留它们以保持现有构建可用，不能全部直接删除。`.vscode/settings.json` 关闭嵌套仓库自动发现，减少编辑器源码管理面板中的仓库列表。

新机器克隆本仓库后，源码已齐全，但依赖原始 Git 元数据、系统依赖和编译产物仍需恢复/构建；不能把此仓库视为无需安装即可运行的系统镜像。恢复 PX4 上游仓库元数据时，需按 `dependency-sources.json` 的版本在临时位置获取仓库及子模块，先备份再迁入元数据，保留本仓库的定制源码；不要用上游 checkout 覆盖比赛修改。

如只想从编辑器列表移除某个依赖仓库，可在源码管理面板选择关闭该仓库，无需删除实际源文件。
